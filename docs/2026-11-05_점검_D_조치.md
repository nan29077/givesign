## 운영 권고 — LibreOffice 변환 (코드로 막을 수 없는 부분)

코드에서 한 것: `execFile` 배열 인자(셸 없음), 90초 시간 초과 + `SIGKILL`, 출력 상한 1MB, 매번 새 임시 프로파일에
매크로 보안 "매우 높음"·매크로 실행 끔·`BlockUntrustedRefererLinks` 설정, 임시 폴더를 `HOME` 으로.

운영에서 해야 할 것:

1. **네트워크를 막은 환경에서 변환한다.** 문서 안 외부 그림·필드(INCLUDEPICTURE, OLE 링크)를 LibreOffice 가
   가져오는 경로는 프로파일 설정만으로 모두 막힌다고 보장할 수 없다. 변환 전용 컨테이너(예: `--network none`)나
   아웃바운드를 차단한 보안 그룹에서 `soffice` 를 돌리고, 앱 서버는 파일만 주고받게 한다.
2. **큐/워커로 분리한다.** 지금은 업로드 요청 안에서 최대 90초 동기 실행한다. 동시 업로드가 몰리면 앱 서버 메모리를
   잡아먹으므로, 운영 규모에서는 변환을 별도 워커로 옮긴다.
3. **남은 `soffice.bin` 정리.** 시간 초과 때 `SIGKILL` 은 직접 띄운 프로세스에만 간다. 변환 환경에 주기적으로
   오래된 `soffice.bin` 을 정리하는 감시를 둔다.
4. LibreOffice 는 최신 보안 패치 버전을 유지한다.

## 운영 권고 — S3 구성

- `S3_PREFIX`(공개, 기본 `uploads`)와 `S3_PRIVATE_PREFIX`(비공개, 기본 `private`)는 서로 다른 최상위 접두사여야 한다.
- `S3_PUBLIC_BASE`(CloudFront 등)를 쓰면 배포 원본 경로를 `uploads/` 로만 제한하고, 버킷 공개 정책에서 `private/` 를 뺀다.
  부팅 때 `[storage]` 경고로 같은 내용을 남긴다(`storageWarnings`).
- 이 조치 전에 `uploads/` 에 올라간 `.ttf`·`.otf` 는 `private/` 로 옮긴다(읽기는 두 곳을 모두 보므로 옮겨도 서식은 그대로 그려진다).
- 이 조치 전에 올린 글꼴은 `document_font_asset` 행이 없어 렌더에 쓰이지 않는다(운영 데이터 없음 전제). 그런 서식은 글꼴을 다시 올리면 된다.

## 고치지 않았거나 일부만 고친 것

- 서명 이미지 PNG 의 `/api/media` 공개 캐시: 일반 이미지와 이름 형식이 같아 구분할 수 없다. 문서류(PDF·워드·한글)만
  `Cache-Control: private` 로 바꿨다. S3 + CDN 구성에서는 업로드 때 지정한 캐시 헤더가 그대로 쓰인다.
- 확인서 열람 사건: 해시 체인에 넣지 않고(열람마다 끝값이 바뀜) 쓰이지 않던 `CERTIFICATE_VIEWED` 라벨을 지웠다. 열람은 감사로그(`EDOC_CERTIFICATE_VIEW`)에 남는다.
- 서식 PDF 해시 대조: 운영 점검 배치 대신 완료 확인서를 열 때 1회 대조해 결과를 확인서에 적는다.
