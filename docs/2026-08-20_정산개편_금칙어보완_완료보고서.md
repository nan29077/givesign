## 1. 정산 관리 탭 개편

후원 설정과 동일한 탭 UI로 4개 탭 분리: **정산 현황**(요약·캘린더·누적요약) / **정산 요청**(요청 폼+내역) / **정산 계좌** / **정산 원장**(수수료 정책+원장). 기존 `/studio/settlement/account` 는 계좌 탭으로 리다이렉트 유지.

## 2. 출금 요청 시 주민등록번호

정산 요청 폼에 주민번호 입력(앞6+뒤7, 뒤 7자리는 password 마스킹) + **수집·이용 별도 동의 체크박스** + **안내 문구 필수 노출**:

> "입력하신 주민등록번호는 소득세법에 따른 원천징수 신고에만 사용되며, **신고 완료 후 즉시 파기**됩니다. 암호화되어 저장되고 어떤 화면에도 원문이 표시되지 않으며, 화면에는 마스킹된 값만 보관됩니다. (지급명세서 등 세법상 보존 대상 서류는 주민등록번호를 제외하고 유지됩니다.)"

- 형식·체크섬 검증 후 **AES 암호화 저장**, 화면에는 `901010-1******` 마스킹만
- 이미 등록(파기 전)된 번호가 있으면 재입력 없이 재사용, "변경" 버튼으로 갱신
- 원문은 서버 내부(지급명세서 산출)에서만 복호화, 조회 화면 없음

## 3. 쿠콘 지급대행 정산 로직

관리자 정산 화면에 지급대행 운영 툴바를 추가했습니다. 흐름: **요청 선택 → 일괄 승인 → 지급대행 파일 받기 → 쿠콘 이체 실행 → 결과 반영**.

- **일괄 승인/반려/지급** (체크박스 다중 선택). 반려 사유 필수
- **지급대행 이체파일(CSV) 다운로드** — 순번·은행코드·계좌번호·예금주·금액·적요. Excel 한글 BOM, CSV 인젝션 방지. 미인증 계좌는 제외
- **지급결과 반영** — `요청ID,SUCCESS|FAIL,사유` 붙여넣기로 일괄 반영
- **지급 실패(PAYOUT_FAILED)** 상태 신설 — 이미 지급 분개가 있으면 잔액으로 **환입**해 재요청 가능
- **상태 변경 알림** — 승인·반려·지급완료·지급실패 시 사회복지기관 알림함에 발송
- **원천징수 지급명세서 자료(CSV) 다운로드** — 지급완료 기간별 내역(과세소득·원천징수·주민번호 상태)
- **원천징수 신고 완료·주민번호 파기** — 신고 후 주민번호 원문만 파기(마스킹·금액·원천징수 기록 유지)

지급 검증(승인 상태·계좌 인증·잔액 재확인)과 원장 append-only 는 그대로 유지됩니다.

## 4. 라이브 스위치 버그 — 확인·수정 완료

직전에 발견한 원인(입력칸 이름 `youtubeLiveUrl` ↔ 저장 로직 `liveUrl` 불일치)과 동일 계열로, 이미 수정되어 있습니다. 재검증에서 저장·새로고침 유지·온에어·두근두근·링크 연결 모두 정상 확인.

## 5. 이미지 첨부 (URL + 파일 업로드)

프로필 아바타·후원페이지 배너에 **파일 업로드 / URL 입력 겸용** 필드 추가.

- 업로드는 `/api/upload` — 사회복지기관 로그인 + 동일출처(CSRF) + **매직바이트로 실제 형식 판정**(확장자·MIME 위조 방지) + 5MB 제한
- 저장은 서버 로컬(`var/uploads`), 예측 불가 랜덤 파일명, `/api/media/<파일>` 로 서빙 (S3 전환 대비 분리)
- 업로드 후 미리보기 + 지우기. **위조 이미지(텍스트를 png로 위장)는 400 거부** 확인

> `next start` 는 빌드 이후 `public/` 에 추가된 파일을 서빙하지 않으므로, 정적 경로 대신 전용 미디어 라우트로 서빙하도록 구현했습니다.

## 6. 금칙어 점검 결과 + 보완

**점검**: 차단/마스킹/표시 3방식, 개인정보 자동 마스킹, 스코프 격리, 후원자 차단 — 모두 정상(유닛 검증 완료).

**보완 4가지**:

1. **금칙어 미리보기** — 문장을 넣어 통과/마스킹/차단 결과를 실제 후원 없이 확인
2. **차단 이력** — 금칙어로 접수 거부된 최근 문자와 사유 표시(조정 근거)
3. **우회 표기 대응** — "바 보", "바.보", "바_보" 처럼 글자 사이 공백·기호를 낀 우회를 잡음. 다른 글자가 낀 경우(노트북 출력)는 오탐하지 않음
4. **기본 비속어 세트** — 자주 쓰는 비속어를 마스킹으로 한 번에 추가하는 버튼

## 참고 / 남은 사항

- **세무**: "신고 후 즉시 파기"는 주민번호 원문에 한정했습니다. 지급명세서·원천징수 서류 자체는 세법상 보존(통상 5년) 대상이라 유지합니다. 자동 파기 시점의 정책(예: 미신고분 보관 기한)은 세무 자문 후 설정으로 조정 가능하게 열어두었습니다. 저는 세무 전문가가 아니므로 최종 확정은 세무 자문을 권합니다.
- **쿠콘 규격**: 이체파일 열 순서·인코딩은 표준형으로 만들었으며, 쿠콘 연동규격서 수령 시 헤더만 대조하면 됩니다.
- **이미지**: 현재 서버 로컬 저장이라 서버 이전 시 `var/uploads` 를 함께 옮겨야 합니다. S3 도입 시 `src/server/uploads.ts` 와 업로드/미디어 라우트만 교체하면 됩니다.
