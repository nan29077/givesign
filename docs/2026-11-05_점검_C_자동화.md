  `runNoticeNowAction` 은 `runMerchantNotice` 를 바로 호출하고, `/api/cron/monthly-notice` 는 Redis 잠금(`runCronJob`)을 쓰지만 수동 실행은 그 잠금 밖이다. - 영향: 월간 안내가 같은 사람에게 2회 발송(비용·민원), `notice_run` 집계도 두 실행이 각각 `increment` 해 부풀려진다. CLAUDE.md 11항 "월간 안내는 … 한 번만" 위반.
