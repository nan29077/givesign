## 3. 스위치 동작

- 위치: 관리자 > 시스템·보안 > **사이트 설정** (최고관리자만 변경). 기본값 꺼짐.
- 켜기: 확인창 후 즉시. 끄기: 진행 중 건수·셀러브릭스 수동 조치 안내를 보여 주고 '끄기' 입력해야 꺼짐.
- 꺼지면 사라지는 것: 메인 소개 섹션, 공개 `/bazaar`·가입, 서랍 메뉴·푸터 링크, 사이트맵, 회원가입 안내, 기부자 콘솔 전체, 기관 콘솔 메뉴·화면, 관리자 메뉴·화면, 모든 서버 액션, 파일·CSV API. 주소는 일반 404(바자회 문구 없음). 기부 회원이 로그인하면 메인으로 이동.
- 꺼져도 남는 것(대표 결정): 관리자 `/admin/in-kind-settlements`(제목 "현물 판매 정산", 사이트 설정에 미지급 건수 링크), 기관 기부금영수증 메뉴의 현물 영수증·홈택스 명세.
- 셀러브릭스 쪽은 자동으로 숨겨지지 않는다(연동 전). 끌 때 바자회 센터 창고 상품 비활성·예정 방송 취소를 운영자가 한다(끄기 확인창에 안내).

## 4. 업무 규칙(코드로 강제)

- 금지 품목(건강기능식품·의약품·주류·담배 등)과 유통기한 30일 미만은 접수 거절
- 매칭은 참여 승인 + 공익법인 지정 확인 기관만, 수락 기한(기본 3일) 지나면 접수 상태로 복귀, 거절한 기관에는 다시 제안 불가
- 가액: 상대가 낸 마지막 제안을 수락해야 확정(자기 제안 자기 확정 불가)
- 약정: 스냅샷 + SHA-256 보관, 약정 뒤에는 기부자 취소 불가(관리자만, 영수증 전까지)
- 영수증: 기관 검수 확정 시에만, 금액 = 확정 단가 × 합격 수량, 개인은 영수증 정보(주민번호) 없으면 발급 거절 후 전체 되돌림
- 상품: 판매가 ≥ 최소 판매가(기본 5,000원) 및 기부자 최저가, 수량 ≤ 합격 수량
- 판매 결과: 추적 코드 없는 줄(임시상품) 거절, 누적 판매 수량 초과·환불 초과 거절, 입력자 ≠ 승인자(최고관리자는 사유 기재 시 단독 승인)
- 원장: append-only, 멱등키, 수수료 공급가액·부가세 분리, 확정된 달 이후 판매는 다음 달로
- 정산: 집계(재계산 가능) → 확정(금액 고정) → 지급 기록(원장 지급 행), 0원 이하 지급 불가

## 5. 남은 일(코드 밖·2단계)

- 세무·법무: 위탁판매 계약서, 위탁판매 부가세 처리, 현물 가액 기준, 바자회 약관·개인정보 처리 항목
- 셀러브릭스: 실제 PG·카테노이드 계약(판매 실오픈 시점), 바자회 센터 창고 등록
- 2단계 연동: 상품 자동 전송, 판매·환불 자동 수신(`source=API`), 판매자=기관 표기, 임시상품 차단, 반품·교환, 스위치 동기화, 구매자 마이페이지
- 알림(알림톡·문자) 연동은 이번 범위에 넣지 않았다. 진행 상황은 콘솔 화면으로 확인한다.

## 6. 브라우저 시뮬레이션 결과 (55/55 통과)

프로덕션 빌드(`npm start`) + 초기화한 시드 DB 에서 관리자·기관·기부자·비회원 브라우저 4개로 실제 클릭했다.

1. **OFF 전수 확인(10)**: 메인·회원가입·사이트맵에 바자회 없음, `/bazaar` `/bazaar/join` `/giver` `/studio/bazaar` `/admin/bazaar` 404, 관리자·기관 메뉴에 없음
2. **켜기·설정(4)**: 사이트 설정에서 켜기, 창고 주소 저장, 메인 소개 섹션·관리자 메뉴 표시
3. **기관 참여(2)**: 위탁판매 동의·신청 → 관리자 승인
4. **기부(3)**: 기업 회원 가입, 금지 품목(건강기능식품) 접수 거절, 기관 지정 기부 접수 → 자동 매칭 제안
5. **매칭·가액·약정(4)**: 기관 수락 → 기부자 제시 가액 확정 → 기부자 약정 → 창고 주소 안내·송장 저장
6. **입고·영수증(3)**: 관리자 일부 합격(100개 중 95개) 등록 → 기관 검수 확정 → 현물 영수증 `GIV-8K2M-2026-H000001` 285,000원(95×3,000, 사업자번호 기재)
7. **상품·편성(5)**: 셀러브릭스 등록 완료, 셀러 추가, 편성 제안 → 기관 승인, 메인 "다가오는 라이브" 표시
8. **판매·정산(7)**: 추적 코드 없는 임시상품 줄 거절, 판매 20개·100,000원 + 환불 1개·5,000원 입력, 최고관리자 단독 승인(사유) → 귀속 66,500원, 집계·확정·지급 기록, 기관 화면 "지급 완료 66,500원", 기부자 화면 "19/95 · 95,000원", 기관 영수증 메뉴에 현물 영수증
9. **CSV·권한(5)**: 셀러브릭스 등록 정보·기부자 대장·판매 양식·현물 기부 대장 내려받기, 기부자는 관리자 CSV 불가
10. **끄기 후(12)**: '끄기' 입력 없으면 거절 → 끄기, 메인·`/bazaar`·기부자 콘솔·기관·관리자 모두 사라짐, 기부자 재로그인 시 메인으로, **예외** 정산 지급 화면 열림·기관 현물 영수증 유지, 파일·CSV API 404

### 시뮬레이션 중 발견해 고친 것

- **판매 결과 붙여넣기 첫 줄 누락(버그)**: 첫 줄 상품명에 "상품"이 들어 있으면 머리줄로 잘못 보고 버렸다. 임시상품 줄이 거절 안내 없이 사라지는 문제. 머리줄 판정을 "추적 코드가 없고 둘째 칸이 숫자가 아닐 때"로 고치고 회귀 테스트를 추가했다.
- **스위치 반영 지연**: 켠 직후 다른 화면이 최대 3초 동안 꺼진 상태로 보였다(화면 묶음마다 설정 캐시가 따로). 캐시를 1초로 줄였다.
