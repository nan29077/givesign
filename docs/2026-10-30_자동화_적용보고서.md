## 4. 지킨 원칙

- **mock 은 성공을 꾸미지 않는다**: SNS mock 게시는 주소·조회수를 만들지 않고 "mock — 실제 게시 안 됨" 으로 표시. 음성·영상 공급자가 없으면 만들지 않았다고 남긴다. 전자서명은 사람이 모의 화면에서 눌러야만 결과가 바뀐다. 운영에서 `*_ENABLED=true` + mock 이면 부팅 거부.
- **광고성 발송 없음**: 알림톡은 정보성 템플릿만. 재안내는 본인이 '정기' 를 보낸 사람에게만. 명단 업로드는 동의 확인·근거를 받고 광고에 쓰지 않는다.
- **멱등**: 월간 안내 (기관,월)+(실행,후원자), 콘텐츠 단계 (콘텐츠,단계), 게시 (콘텐츠,플랫폼)+조건부 클레임, 봉사 신청 부분 유니크, 예약어 10분 억제.
- **사후 처리 실패가 본 처리를 바꾸지 않음**: 약정서 생성·서명 요청·안내 실패는 약정·신청 결과를 되돌리지 않는다.
- **개인정보**: 비상연락처·명단 번호 3분리 저장, 스냅샷·CSV·화면은 마스킹 번호만.

## 5. 외부 항목 ↔ 여는 방법

| 외부 항목 | 여는 방법 | 그 전 상태 |
|---|---|---|
| 알림톡 중계(coolsms·emma) 연동 | `ALIMTALK_PROVIDER` 실구현 + `SAFE_MODE=false` | mock 기록, 운영은 문자 |
| 기관별 카카오 채널·템플릿 승인 | 관리자 > 자동화 운영 > 사용 중으로 | 문자 대체 |
| 구글 API 감사 / 메타 앱 검수 | `SOCIAL_PROVIDER` 실구현(OAuth·업로드) | 내려받아 직접 게시 |
| 전자서명 계약 | `ESIGN_PROVIDER` 실구현 + 콜백 라우트 | 동의 기록 약정서 |
| AI 공급자(LLM·이미지·TTS·영상) | `CONTENT_PROVIDER` 실구현 | 서식 대본 + SVG 장면 |
| 헥토 무PIN 출금 / 카드 PG / 본인인증 | 기존과 같음 | 기존과 같음 |

배치 등록: `/api/cron/monthly-notice` 매월 1일 10:00 KST, `/api/cron/content` 1시간마다 (둘 다 `Authorization: Bearer ${CRON_SECRET}`).
