## 2. 만든 것 (차수별)

### 1차 — 실패를 줄이고 사람이 할 일을 한 곳으로
- **정기후원 실패 원인별 복구**: 잔액 부족은 급여일 근처 재시도, 계좌·인증·결제수단 문제는 자동 재시도 없이 후원자 복구 링크(`/r/recover/[토큰]` — 재등록·출금일·금액 변경·이번 달 쉬기·해지) + 승인 대기함 "정기후원 복구" 묶음. 결제사 코드표는 환경변수(`RECURRING_CODES_*`) — 비면 예전 동작.
- **(선택) 기관 소식·후원 안내 수신 동의**: 후원 화면 5곳에 기본 해제 체크칸. 동의만 쌓고 이 동의로 보내는 기능은 5차 관계 안내뿐(꺼짐 기본). 탈퇴 시 자동 철회.
- **MO 단계별 이탈 측정**: 문자 수신 → 회신 → 링크 열람 → 금액 선택 → 인증 → 완료, `/studio/reports?tab=funnel`.
- **콘텐츠 자동 승인 폐지**: 생성은 자동, 게시는 항상 담당자 승인. 주간 묶음 승인 `/studio/content/review`, 반려·수정 요청(새 판), 게시 전 알림.
- **승인 대기함 예외 해결**: 원인별 묶음·영향 인원·권장 조치·바로 실행, 담당·기한·기한 넘김 알림, 영수증 일괄 발급 승인 전 확인 화면.
- **문서 발송 전 점검**: 필수 빈칸·연락처 없음·금액 이상·미래 연도는 막고, 긴 이름 넘침·모르는 필드는 경고. 표본 미리보기.

### 2차 — 판단·발송·입금·셀프서비스
- **후원자별 "다음 할 일"**(규칙 기반) + 열린 문의·진행 중 환불이면 자동 안내 보류.
- **정보성 안내 통합 발송**: 같은 후원자 안내를 10분 모아 한 통, "7일 3건" 상한을 모든 정보성 안내 합산, 야간 금지. `OUTBOUND_COORDINATOR=off` 로 예전 방식.
- **입금 자동 대사** `/studio/deposits`: 은행 거래내역 파일(CSV·XLSX, 국민·신한·우리·하나·농협) → 자동 확정(확실한 것만)/확인 필요/모름. 기브싸인 결제·정산·캠페인 모금액과 섞지 않음. 영수증 포함은 기관 설정(기본 끔).
- **후원자 셀프서비스**: 정기후원 변경·쉬기·해지(결과 문장 미리보기, 휴대폰 재확인), 영수증 정보, 받은 문서, 알림 설정 — 통합 `/my` 와 기관 후원 회원 화면 모두.

### 3차 — 계획·보고·법정 서류
- **기관 목표 → 주간 운영 계획 → 월요일 보고**: 숫자는 원천 계산, 제안 실행은 승인 요청만(게시·발송 없음).
- **콘텐츠 성과 폐루프**: 콘텐츠별 클릭·후원·약정 귀속, 잘된 요소를 다음 생성에 반영, 두 안 비교(둘 다 승인 필요), 얼굴 사진은 초상권 동의서 연결 필수.
- **후원금 사용 결과 보고** `/studio/impact`: 개인별 사용처 문장·권유 문구 금지, AI 초안 숫자 검증, 승인 후 참여 후원자에게 발송.
- **법정 서류** `/studio/reports/legal`(재무·회계 규칙 제41조의4~7 요약 — **법령 서식과 대조 필요** 표시): 후원금 수입·사용결과 보고서 작성 보조(PDF·CSV), 공개용(이름 없음), 영수증 발급 대장, 지정 용도 외 사용 경고, 후원자 연 1회 통보(승인 후 발송).

### 4차 — 캠페인·기관 도입·문서 묶음·문자 창구
- **캠페인 개설 마법사**: 한 번 입력으로 후원페이지·키워드·QR·콘텐츠 일정 초안·감사 문구·종료 후 방침·결과 보고 예정일. 변경 영향 미리보기, 목표 달성·진행 부진 제안.
- **기관 도입 체크리스트** `/studio/start`, 서류(고유번호증) 자동 읽기(OCR 어댑터 — 연결 전 표시), 시험 후원·시험 문서(집계에 안 섞임), "작동 확인됨" 점검, 하루 1회 자가 진단.
- **서식 자동 인식**: 이름·금액·출금일 등 자리 후보 제안(담당자 수락 필요, 주소·생년월일 제외).
- **업무별 문서 묶음**: 본인확인 1번 + 한 화면 서명. 요금 규칙 무변경(문서 1건 = 1건 차감), 발송 비용 예측, 충전 후 멈춘 발송 자동 재시도.
- **홍보물별 성과**(현수막·소식지·QR별 키워드), QR → 문자 앱 바로 열기, 알아듣지 못한 문자는 캠페인·금액 미리 고른 화면으로(결제는 후원자가 누름).
- **문자 명령 창구**: 영수증·내역·변경·해지·문의 → 결제 없이 본인확인 링크. 기존 캠페인 키워드가 같은 단어면 기존 동작 우선.
- **문의 자동 응대**: 정해진 답이 있는 분류만 기관이 켠 경우 자동 답변(기본 꺼짐), 불만·환불·법적은 항상 담당자.

### 5차 — 계약이 필요한 연동의 틀 + 관계 안내 (모두 기본 꺼짐)
- **본인인증**(PASS·NICE 자리, mock), 영수증 정보·전자서명·정기 해지/변경에 플래그별 적용. **시점확인(TSA)** 은 "미연동" 기록만.
- **카드 일시후원**(카드 PG 자리, mock): 기존 결제 보호 장치 그대로, 카드 수수료 정책 별도, 정기후원은 계좌만.
- **계좌 거래내역 자동 조회**(오픈뱅킹 자리, mock): 파일 업로드와 같은 규칙·중복 방지.
- **관계 확장 안내 4종**(일시→정기, 휴면 재참여, 증액, 봉사자→후원자): 최고관리자 "법무 확인 완료" + 기관 설정 둘 다 켜야 동작, 동의자만·주 1회 기관 승인·(광고)·무료 수신 거부·21~8시 금지·월 1회·수신 거부율 2% 초과 시 자동 중지.
- 운영에서 켰는데 공급자가 mock 이면 서버가 뜨지 않음(가짜 성공 없음).

## 5. 결정이 필요한 것

**법무·세무**
1. 법정 서류: 별지 제19호서식 항목 대조, 구청 제출본에 후원자 이름 포함 여부(지금은 이름 없이 생성).
2. 연 1회 통보에서 월간 안내 수신 거부자를 빼도 되는지.
3. 관계 안내 켜기 전 법무 확인(정보통신망법 제50조) — 080 무료 수신 거부 번호 계약 여부, 월 1회를 후원자 전체 기준(지금)으로 할지 기관별로 할지.
4. 개인정보 처리방침·약관 개정 문안(본인인증·카드·계좌 조회·광고성 정보) — 5차 작업 보고의 제안 문안 기준으로 검토. 약관 개정 시 `TERMS_VERSION` 올리고 재동의.

**계약·외부**
5. 헥토 정기 출금 실패 코드표(받으면 환경변수만 채움), 본인인증(PASS/NICE)·카드 PG·오픈뱅킹 규격 수령 후 실연동, OCR(Anthropic 키) 사용 여부.

**운영 정책**
6. 약정서 출금일이 비었을 때 경고만(지금) vs 발송 막기.
7. 여러 안내를 묶은 메시지는 장문 문자로 나감 — 알림톡 여러 통과 비용 비교 후 결정.
8. 월요일 주간 보고는 기관 담당자 대상이라 후원자 안내와 다른 경로로 발송(지금 방식 유지 여부).
9. 시험 후원은 시뮬레이션만(실제 문자 미발송) — 유지 여부.
10. 명령어와 같은 단어를 이미 캠페인 키워드로 쓰는 기관은 캠페인 우선(관리자 화면 경고) — 유지 여부.
11. 계좌 미등록 후원자에게도 MO 에서 카드 선택지를 열지(웹 후원은 이미 가능).
12. 기관 후원 회원 화면의 영수증 정보 저장은 재확인 후, 통합 화면은 기존대로 — 같은 규칙으로 맞출지.
13. 복구 링크 경로에도 "결과 미확인 출금 중 변경 보류"를 적용할지(지금은 셀프서비스 경로만).
