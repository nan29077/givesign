- 승인은 기록과 실행을 나눈다(대량 작업은 배치가 실행). 처리 중 15분 정체는 자동 복구.
- 알림톡 접수는 성공이 아니다(`ACCEPTED` → 결과 조회 → `SENT`/문자 대체/`UNKNOWN`).
- SNS 결과를 모르는 게시는 자동으로 다시 올리지 않는다(`UNKNOWN` → 담당자 처리).
- 바자회: 정산 이월, 기관별 잠금, 제안 id 확정, 참여 승인 가드, 요율 고정, 반환 정정, 파일 선검증.
